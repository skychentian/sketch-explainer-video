# 批量做多条

1. **收集文案**：每条存一个 txt（一字不改），文件名带序号，如 `v06.txt`。
2. **建工程**：`new_video.sh` 可以同时开多个（各自用已绑定的 MiniMax 或豆包 Key 合成；本地识别有全局锁会自动排队）。每条独立目录，如 `videos/v06-xxx/`。没绑定时先停下来，引导对方绑定其中一家。
3. **写画面**：每条交给一个子任务（subagent / 另一个会话）。给它的指令只需要：工程目录、视频标题、主视觉提示（如“这条是步骤清单型”），并要求它先读本 skill 的 SKILL.md 和 components.md。
   - 子任务的临时文件只写在各自工程目录（如 `./.work/`），共享临时目录会互相覆盖同名文件。
4. **统一验收**（协调者自己做，不要只信子任务的汇报）：每条跑一次 `check.py`，打开 contact sheet 看；把画面上的数字、日期、标准名、电话号码逐个 grep 回 `user_script.txt` 确认出自原文。
5. **交付**：统一命名（如 `视频06-标题-简笔画成片.mp4`），列出每条时长、配音、需要人工留意的概括性文字。
